# שינון

אפליקציית לימודים בעברית לתלמידי תיכון. התלמיד מעלה PDF או מצלם דף סיכום,
והמערכת מחזירה שלושה דברים: סיכום מסודר, כרטיסיות שאלה־תשובה, וקוויז אמריקאי.
הכול בעברית, והכול מבוסס אך ורק על החומר שהועלה.

## מה קיים כרגע

שלב 3 — השלד ומסך הבית, על מערכת העיצוב מ־`design/`.

- Expo (React Native) + TypeScript, ניווט קבצים עם expo-router
- RTL מלא, נאכף לפני הרינדור הראשון
- מערכת העיצוב של האתר, מומשת בטוקנים: Assistant + JetBrains Mono, פלטת
  הנייר והדיו, רקע גרעיני
- מסך בית: רשימת החומרים + כפתור העלאה, כולל מצב ריק ומצב טעינה
- החוזה של תשובת השרת, כולל ולידציה בזמן ריצה (`src/types/study.ts`)
- מסך העלאה — שלד ריק בלבד, נבנה בשלב הבא

## הרצה

```bash
npm install
npm start          # ואז i / a לפתיחה במדמה
npm run typecheck
```

להצגת חומרי הדגמה במסך הבית בזמן פיתוח:

```bash
EXPO_PUBLIC_SEED_DEMO=1 npm start
```

## כללי ברזל

1. **מפתח ה־API של המודל נמצא רק ב־Secrets של ה־Edge Function**, אף פעם לא בקוד
   האפליקציה. `assertNoModelKeyInApp()` ב־`src/config/env.ts` נופל בזמן פיתוח אם
   מפתח כזה מסתנן ל־`EXPO_PUBLIC_*`.
2. האפליקציה שולחת את התמונה/PDF לפונקציה. הפונקציה היחידה שמדברת עם המודל.
3. **בלי OCR ובלי חילוץ טקסט מ־PDF.** עברית נשברת בשתי הדרכים — כתב יד לא מזוהה,
   ו־PDF עברי מחזיר טקסט הפוך ומשובש. כל עמוד מומר לתמונה ונשלח למודל ראייה.
4. **RTL מלא מהרגע הראשון.** `enforceRTL()` נקרא ברמת המודול של `app/_layout.tsx`.
5. הפונקציה מחזירה JSON בלבד, במבנה שמוגדר ב־`src/types/study.ts`.
6. הפרומפט למודל מצהיר במפורש: כל הפלט בעברית, אך ורק מהחומר שהועלה, בלי ידע
   חיצוני, בלי להמציא.
7. מגבלת הוצאה: ספירת קריאות בטבלה, ועצירה מעל תקרה חודשית.

## עיצוב

מערכת העיצוב יושבת ב־`design/`, וכל הערכים שלה מיוצגים ב־`src/theme/tokens.ts`.
צבע או גודל חדש נכנס לטוקנים, לא לתוך מסך בודד. הפירוט המלא, כולל ההבדלים
המכוונים בין האתר לאפליקציה, ב־`design/README.md`.

## הערות RTL

- `I18nManager.forceRTL(true)` ב־native נכנס לתוקף אחרי רילוד אחד. לכן כל הסטיילים
  מצהירים במפורש על `textAlign: 'right'` ו־`writingDirection: 'rtl'`, ושורות
  משתמשות ב־`rowDirection` — כך הממשק נכון גם בהרצה הראשונה.
- חצים מצוירים ב־`Chevron`, לא נכתבים כתווים. תווים כמו `‹` הם bidi-mirrored
  ומתהפכים לבד לפי כיוון הפסקה.
- מחרוזת שמתחילה במילה לטינית (למשל "PDF או צילום") מקבלת כיוון פסקה LTR
  ומילותיה מסתדרות הפוך. כל טקסט מתחיל במילה עברית.
- משקלים דרך `fontFamily` ולא `fontWeight` — ב־Android משקל לא עובד על פונט
  שנטען כמשפחה נפרדת.
