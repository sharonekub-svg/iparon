# אתר הנחיתה

הגרסה הפרוסה של העיצוב מ-`design/`, כאתר סטטי בלי תלויות: HTML, CSS ו-JS אחד.
הכרטיסייה, הקוויז והשאלות הנפוצות עובדים באמת בדף — התוכן הוא המוצר, ולכן הוא
לא צילום מסך.

## חיבור לוורסל

צריך חשבון Vercel — זה שלב בדפדפן שאי אפשר לעשות מהקוד:

1. `vercel.com/new` → Import Git Repository → הריפו הזה
2. **Framework Preset: Other**. את ה-Output Directory אין צורך למלא —
   `vercel.json` בשורש כבר מצביע על `site`, ואין שלב build.
3. Deploy. מכאן כל פוש ל-main מעלה גרסה חדשה, וכל פוש לענף אחר מקבל
   Preview URL משלו.

האפליקציה עצמה לא עוברת בוורסל.

## מה עוד לא מחובר

**רשימת ההמתנה לא שולחת לשום מקום.** הטופס מאמת את הכתובת ומציג אישור, אבל
אין backend מאחוריו — הכתובת נשארת בדפדפן ונעלמת. זה מכוון: עדיף טופס שלא
שולח מכתובת שנאספת לשום מקום ואף אחד לא רואה.

לחיבור אמיתי, ב-`app.js` בפונקציית ה-submit במקום `form.hidden = true`:

- **ספק דיוור** (Buttondown, Mailchimp, Loops) — `fetch` ל-endpoint שלהם
- **Supabase** — טבלת `waitlist` עם policy של insert בלבד, קריאה ישירה
  מהדפדפן עם מפתח ה-anon
- **Vercel Form** — `<form action="/api/waitlist" method="post">` עם פונקציה

## פונטים

Assistant ו-JetBrains Mono נטענים מ-Google Fonts, כמו בקובץ העיצוב. אם רוצים
לוותר על התלות החיצונית — להוריד את הקבצים ל-`site/fonts/` ולהחליף את ה-`link`
ב-`@font-face`. זה גם מונע מ-Google לראות את מבקרי האתר.

## שינויים בקופי מול קובץ העיצוב

שלוש טענות בקובץ העיצוב לא תיארו את המוצר כמו שהוא נבנה, ותוקנו כאן:

1. **"קובץ Word" הוסר** מרשימת סוגי הקבצים. כל עמוד מומר לתמונה ונשלח למודל
   ראייה, ו-`.docx` הוא מסלול אחר שלא בתוכנית.
2. **"שינון פועל בדפדפן, אפליקציה נפרדת בתכנון" הפוך** — מה שנבנה הוא
   אפליקציית Expo, והאתר הזה הוא דף הנחיתה אליה. התשובה עודכנה בהתאם.
3. **הבטחת הפרטיות הוסרה.** "לא נגיש לאף אחד מלבדך" דורש התחברות שאין
   בגרסה הזאת, ואי אפשר לאכוף אותה. עדיף לא להבטיח מלהבטיח ולא לקיים.
   כשתתווסף התחברות ו-RLS, אפשר להחזיר אותה.

הבדיקה החזותית של הדף היא `site/index.html` עצמו. אין שלב build.
