# חסם כניסה — השאלה היחידה שחשובה

חסם אמיתי הוא אחד מהשלושה: אפקט רשת, נתונים שאין לאחרים, או מותג.

לרוב הרעיונות שלי אין אף אחד מהם חוץ מ[[רעיון-מפת-מגרשים]] ו[[רעיון-לוח-מודעות-שכונתי]]
