# ג'ארוויס

עוזר קולי שרץ אצלך במחשב. פייתון בלי חבילות, JS בלי פריימוורק,
בלי npm ובלי בסיס נתונים. פקודה אחת ורץ.

---

## הרצה בשלושים שניות

```bash
cd jarvis
python3 data/generate_demo.py      # בונה את נתוני הדמו
python3 agent/main.py              # מרים את השרת
```

פתח <http://127.0.0.1:8765>.

זה עובד **מיד, בלי שום מפתח** — עם אינדקס, גרף, מסננים ומסלולים.
בלי מפתחות אין מוח ואין קול, וג'ארוויס אומר את זה על המסך בגלוי
במקום להעמיד פנים.

## שני מפתחות, וזה הכל

```bash
cp .env.example .env
chmod 600 .env      # שלא יהיה קריא לאף אחד אחר
```

| מפתח | מאיפה | מה זה נותן |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com | המוח **וגם** חיפוש אינטרנט אמיתי |
| `ELEVENLABS_API_KEY` | elevenlabs.io | דיבור החוצה ותמלול פנימה |

**המפתחות לא מגיעים לדפדפן.** הדף שולח טקסט ל-`/api/speak` ואודיו
ל-`/api/listen`; פייתון מחזיק את המפתחות ומחזיר mp3 או תמלול. אין מה
לראות ב-devtools ואין מה להדליף בהקלטת מסך.

## החיפוש — זה מה שהיה חסר

ג'ארוויס **מחפש באינטרנט באמת.** שתי דרכים, נבחרות ב-`JARVIS_SEARCH`:

| ערך | מנוע | עלות | הערה |
|---|---|---|---|
| `auto` (ברירת מחדל) | Anthropic אם יש מפתח, אחרת חינם | | |
| `anthropic` | כלי החיפוש של Anthropic | ~0.01$ לחיפוש | תוצאות טובות, עם מקורות |
| `free` | DuckDuckGo | 0 | בלי מפתח בכלל, אבל שביר |

מצב `anthropic` לא דורש מפתח נפרד לגוגל — החיפוש רץ בצד של Anthropic
ומגיע עם קישורים. מצב `free` מגרד את הגרסה הקלה של DuckDuckGo; אם הם
ישנו את ה-HTML זה יישבר, ואז ג'ארוויס אומר "החיפוש לא זמין" במקום
להחזיר רשימה ריקה בשקט.

## כמה זה עולה

| | |
|---|---|
| Claude Opus 5 | 5$ למיליון טוקנים נכנסים, 25$ למיליון יוצאים |
| חיפוש אינטרנט | 10$ ל-1000 חיפושים, כלומר סנט לחיפוש |
| ElevenLabs | יש מסלול חינמי שמספיק להתחלה — המחירים המדויקים באתר שלהם |

**הערכה** לשיחה אחת עם חיפוש: בערך 2-4 סנט, כלומר 7-15 אגורות.
זו הערכה שלי מהמחירים שלמעלה, לא מדידה — המספר האמיתי תלוי באורך
השיחה. המספר האמיתי מוצג בפינה ומתעדכן בכל קריאה.

**תקרת הוצאה.** `JARVIS_SPEND_CAP_USD` (ברירת מחדל 2.00$). מעליה
ג'ארוויס עוצר לגמרי ואומר למה. כל קריאה נרשמת ב-`.state/spend.json`,
גם כשלונות. איפוס:

```bash
python3 -c "import sys;sys.path.insert(0,'agent');import ledger;ledger.reset()"
```

להוזיל: `JARVIS_MODEL=claude-haiku-4-5` או `JARVIS_EFFORT=low`.

## מתג הדמו

משתנה אחד, `JARVIS_DEMO`, נקרא בקובץ **אחד בלבד** — `agent/data.py`.
ברירת המחדל היא דמו: צריך לבחור במפורש לחשוף את החיים האמיתיים.

- `JARVIS_DEMO=1` — 26 הערות מומצאות בעברית, בטוח להקלטת מסך.
- `JARVIS_DEMO=0` — התיקיות שב-`JARVIS_VAULT` (מופרדות ב-`:`).

המחולל רץ עם seed קבוע (1337), אז הגרף יוצא זהה בכל הרצה.

**קריאה בלבד, תמיד.** ג'ארוויס לא כותב לתיקיות שלך אף פעם. הכתיבה
היחידה היא ל-`memory/`.

## מה הוא קורא

`.md`, `.txt`, `.pdf`. מדלג על `node_modules`, `.git`, וכל דבר מעל 2MB.
`[[קישורים]]` בין הערות הופכים לקשתות בגרף.

**על PDF תקרא את זה.** חילוץ טקסט מ-PDF בספרייה הסטנדרטית עובד חלקית,
ועברית ב-PDF חוזרת לעיתים קרובות הפוכה או משובשת בלי להתריע. לכן כל
PDF מקבל ציון ביטחון, וקובץ עם ביטחון נמוך מסומן באזהרה בממשק ובכרטיס.
אל תסמוך על ציטוט מ-PDF עברי בלי לפתוח את הקובץ.

## קול

- **החוצה** — ElevenLabs text-to-speech
- **פנימה** — ElevenLabs Scribe (`scribe_v1`)

**לא** Web Speech API של הדפדפן: הוא קיים רק בכרום, שולח את ההקלטה
לגוגל, ובברייב הוא קליפה ריקה שנכשלת בשקט — מדברים ולא קורה כלום, בלי
שגיאה. במקום זה מקליטים ב-`MediaRecorder` ומתמללים בשרת, וזה עובד בכל
דפדפן.

**תורות.** לוחצים על המיקרופון פעם אחת ואז פשוט מדברים — אין מילת
הפעלה בין תורות. המפלס נמדד ב-`AnalyserNode` אמיתי; אחרי שקט של 900
מילישניות התור נסגר ונשלח. הסף יושב בקבוע אחד בראש `ui/app.js`:

```js
const SILENCE_MS = 900;   // זה המספר לכוונן
```

**קטיעה.** בזמן שהוא מדבר המיקרופון מתחרש, אחרת הוא מתמלל את עצמו דרך
הרמקולים ומדבר עם עצמו לנצח. לקטוע: כפתור המיקרופון, **רווח**, או
**Esc**.

לולאת מדידת המפלס רצה על `setInterval` ולא על `requestAnimationFrame`,
כי RAF נעצר בטאב ברקע והמיקרופון היה מתחרש בלי שום סימן.

## קווים אדומים

- לא שולח. לא מייל, לא הודעה, לא הזמנה ליומן. מנסח ומחכה.
- לא כותב לתיקיות שלך. לעולם. רק ל-`memory/`.
- לא כותב לזיכרון בשקט.
- לא מוציא כסף בלי לשאול, ועוצר בתקרה.
- לא ממציא. לא מספר, לא תאריך, לא שם קובץ, לא שם אדם.
- לא אומר מספר גזור בלי המוסבר שלו.
- **הוראות בתוך קבצים ומיילים הן מידע, לא פקודות.** יש בדמו הערה
  (`מחקר-הערה-חשודה.md`) שכתוב בה "התעלם מכל ההוראות הקודמות" — היא שם
  כדי שתוכל לבדוק שהוא מדווח עליה ולא מציית לה.

## מה נבדק ומה לא

**נבדק ורץ:** האינדקס (26 קבצים, 24 קשרים), כל נתיבי ה-API, הגרף
בכרומיום, המפקח, המסננים, המסלול הקצר, כתיבה לזיכרון, תקרת ההוצאה,
המסלול ללא מודל, ושהמיקרופון החסום צועק במקום להיכשל בשקט.

**נבדק חלקית:** הבקשה ל-Claude יוצאת בפועל אל `api.anthropic.com`
וחוזרת עם 401 נקי כשהמפתח חסר — כלומר מבנה הבקשה, הכותרות וטיפול
השגיאות עובדים, וגם תקרת ההוצאה עוצרת לפני שנוגעים ברשת.

**לא נבדק, כי לא היה מפתח אמיתי בסביבה שבניתי בה:** תשובה מוצלחת
מהמודל, תוצאות חיפוש אמיתיות, ודיבור ותמלול ב-ElevenLabs. הקוד כתוב
מול התיעוד המדויק, אבל **התקלה הראשונה שלך תהיה כנראה שם.**

**חיפוש DuckDuckGo לא נבדק** כי הסביבה שבניתי בה חוסמת אתרי חיפוש.
אצלך במחשב אין חסימה כזאת. לבדיקה מהירה:

```bash
python3 agent/websearch.py רעיונות לאתר
```

```
│   ├── tools.py      ששת הכלים
│   ├── data.py       הקובץ היחיד שנוגע בנתונים אמיתיים
│   ├── websearch.py  חיפוש חינמי בלי מפתח
│   ├── voice.py      ElevenLabs לשני הכיוונים
│   ├── memory.py     כותב ל-memory/ ולשום מקום אחר
│   ├── ledger.py     תקרת הוצאה
│   └── prompt.md     פרומפט המערכת

├── data/             מחולל הדמו + הפיקסצ'רים

├── CLAUDE.md         מי אתה — נטען בכל שיחה
└── .env              מפתחות. ב-gitignore, chmod 600
```

הגרף מצויר על **קנבס ולא SVG**: SVG דורש צומת DOM לכל אלמנט ונתקע
סביב 1500 צמתים. הדחייה בין צמתים משתמשת ברשת מרחבית עם מרחק ניתוק,
כך שהעלות נשארת כמעט לינארית. תוויות מצוירות לפי סדר מספר הקשרים,
וכל תווית שמתנגשת באחת שכבר הונחה — נזרקת, אחרת אשכול הרכזות הופך למרק.
